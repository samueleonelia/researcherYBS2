# Sources

One line each: a name, then the page that lists the day's stories.
The number is decoration — delete a source and nothing needs renumbering.

For a paid site, end the line with a third part: text that only appears on the page
when you are logged in, such as Sign Out. A dead session then stops that source
loudly instead of silently collecting teaser pages.
