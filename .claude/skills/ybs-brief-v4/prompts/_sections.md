The sections whose whole output is on beat, matched by code before any agent
sees an article. A match keeps the article and spends no agent on it; anything
unmatched goes to one. Nothing in this list ever throws an article away.

That is why so few are here. A publisher files by department, not by subject, so
a section that is on beat only some of the time belongs to an agent reading the
headline. `article`, `opinion` and every value code does not recognise carry no
subject at all, and are deliberately absent.

Matching ignores case and extra spaces. Adding a source adds its vocabulary
here; leaving this list alone costs agents, never stories.
